# Translation rules for the Greece trip app (English → Latvian)

Audience: a Latvian family, including grandparents, using a phone app on a trip in Greece. Write natural, plain, friendly Latvian, the way a Latvian travel guide would. Avoid word-for-word calques.

## Must keep exactly
- HTML tags and attributes, e.g. `<b>`, `<strong>`, `<a href="#settings">…</a>`, `<span class="muted">…</span>`. Translate only the text inside them.
- Placeholders in curly braces, e.g. `{n}`, `{name}`, `{total}`, `{amount}`. Keep each one; move it wherever Latvian word order needs it.
- Numbers, prices (€72, €10), times (08:30, 18:15), units (km/h, m, °, MB), separators ` · `, arrows `→`, `×`.
- Greek script (μουσακάς, ΑΜΟΛΥΒΔΗ) and Greek transliterations of dishes and words: Moussaka, Souvlaki, Gyros, Tzatziki, Horiatiki, kalamarakia, horta…
- Restaurant names, people's names, phone numbers, e-mail addresses, URLs.
- Brand and app names: Google Maps, Google Sheet, Apps Script, WhatsApp, Wi-Fi, Methoni Boats, NS Boats, Messinia Yachts, Open-Meteo, OpenStreetMap.

## Place names
- Use these established Latvian forms, declined normally: Atēnas, Akropole, Partenons, Erehtejons, kariatīdas, Plaka, Anafiotika, Korintas kanāls, Peloponēsa, Mesēnija, Lakonija, Sparta, Krēta, Mani (indeclinable), Navarīno līcis, Sfaktērija, Senā Mesēne, Mistra, Taigets, Itomes kalns, Kalamata (Kalamatā, Kalamatas), Tripole (Tripoli city), Nafplija, Mikēnas, Epidaura, Sapiencas sala.
- Other villages and beaches keep the spelling on road signs and Google Maps, normally undeclined: Paralia Verga, Pylos, Methoni, Gialova, Voidokilia, Kardamyli, Stoupa, Kalogria, Foneas, Exochori, Artemisia, Areopoli, Limeni, Diros, Gytheio, Mavromati, Polylimnio, Karytaina, Megalopoli, Niokastro, Mets, Pangrati, Makrygianni, Syntagma, Zappeion. Build sentences around them, e.g. "Pusdienas Gialovā" is fine because it reads naturally, but "ciematā Kardamyli" is better than forcing an ending.
- Place titles: translate the generic part and keep the proper name, e.g. "Diros Caves" → "Diru alas", "Ancient Messene" → "Senā Mesēne", "Voidokilia Beach" → "Voidokilia pludmale", "Methoni Castle" → "Methoni cietoksnis", "Panathenaic Stadium" → "Panatēnaju stadions", "Temple of Olympian Zeus" → "Olimpiskā Zeva templis", "Acropolis Museum" → "Akropoles muzejs", "Palace of Nestor" → "Nestora pils", "Corinth Canal" → "Korintas kanāls", "Kalamata Central Market" → "Kalamatas centrālais tirgus", "Polylimnio Waterfalls" → "Polylimnio ūdenskritumi", "Langada Pass" → "Langadas pāreja".
- Dish names: keep the Greek name and translate any explanation, e.g. "Horiatiki (Greek salad)" → "Horiatiki (grieķu salāti)", "Fish of the day" → "Dienas zivs", "Yogurt with honey" → "Jogurts ar medu", "Mountain tea" → "Kalnu tēja", "Greek coffee" → "Grieķu kafija".

## Fixed UI terms (use exactly these)
Today → Šodien · Days → Dienas · Map → Karte · Food → Ēdiens · More → Vairāk · Settings → Iestatījumi · Back → Atpakaļ (both the back button and the return time) · Leave → Izbraukšana · back (lowercase, return) → atpakaļ · Directions → Maršruts · Read more → Lasīt vairāk · Find on map → Atrast kartē · Stories and fun facts → Stāsti un interesanti fakti · In Latvian → Klausīties · Latvian stories → Klausīties stāstus · Play all, in Latvian → Klausīties visus · Listen → Klausīties · Play → Atskaņot · Heads-up → Svarīgi · Swaps and options → Alternatīvas un iespējas · Expenses → Izdevumi · Day order → Dienu secība · Sight → Apskates vieta · Sights → Apskates vietas · Beach → Pludmale · Long day → Gara diena · Relaxed → Mierīga · Medium → Vidēja · Travel day → Ceļa diena · Rest day → Atpūtas diena · Draft → Melnraksts · Whole day in Google Maps → Visa diena Google Maps · Rain plan / If it rains → Ja līst · If it’s dry → Ja ir sauss · Calm sea: boat → Mierīga jūra: laiva · Rough sea: castles → Viļņaina jūra: cietokšņi · Quote needed → Jāprasa cena · Booked → Rezervēts · Free (price) → Bez maksas · 65+ stays 65+ · reduced → atlaide · min → min.

## Style
- Address the reader as "jūs" (plural, polite) with imperatives like "Paņemiet", "Pajautājiet", "Pārbaudiet".
- Buttons are short: Saglabāt, Pievienot, Dzēst, Kopēt.
- Use Latvian quotes „…“ for quoted text.
- Keep it short, about the same length as the English.
